## What it does

`main.ts` writes a single one-line joke about office life (under 200 characters) to `/output/entry.txt`. The output is a fixed string, so every run is byte-identical — no network, no environment input, no randomness.

The joke:

> I blocked focus time on my calendar, so it booked a meeting titled 'Focus Time Sync'.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22 or later.
